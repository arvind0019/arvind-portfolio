## 🎨 Key Features & Highlights

### 1. 🎛️ Ultra-Modern Neumorphic Design System
- **Dual-Tone Color Palettes**: Clean White & Soft Sky Blue (`#eef4fa`, `#0066ff`) paired with Deep Slate Dark Mode (`#0f172a`).
- **Tactile Depth Effects**: Custom multi-layered inset and outset box-shadows (`neu-raised`, `neu-pressed`, `neu-concave`, `neu-convex`) creating soft tactile UI elements.
- **Glassmorphic Accents**: Translucent navigation bar with backdrop blur and dynamic scroll shadow.

### 2. 🪞 3D Interactive Parallax Tilt Profile Card
- **Real-Time Physics Tilt**: Mouse tracking engine calculating dynamic 3D rotational angles (`rotateX`, `rotateY`) and moving holographic glare on the profile photo card.
- **Floating Badge Highlights**: Tactile floating chips for Web Development, AI Tools, and Full-Stack Engineering.

## 🛠️ Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `yarn` or `pnpm`

### 1. Clone the repository
```bash
git clone https://github.com/arvind0019/arvind-portfolio.git
cd arvind-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
